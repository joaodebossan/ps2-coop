Na sua rede—
Fora de casa—

O link de LAN funciona no mesmo roteador. Para fora de casa, o MoonlightWeb usa o link público e a rede precisa permitir UDP.

Se o vídeo não abrir fora de casa

O MoonlightWeb usa UDP. Se a rede bloquear, libere as portas no roteador, use o link público do MoonlightWeb ou uma VPN como Tailscale.
